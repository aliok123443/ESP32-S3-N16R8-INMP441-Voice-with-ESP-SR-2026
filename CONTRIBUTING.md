# Contributing

Thank you for improving Voice Lights.

1. Open an issue before large changes so the goal can be discussed.
2. Create a branch from `main` and keep each pull request focused.
3. Do not commit `build/`, `managed_components/`, `sdkconfig`, generated binaries, or credentials.
4. Test with ESP-IDF v5.3.4 and state the board and wiring used in the pull request.
5. Update the Russian and English sections of the README when user-visible behavior changes.

By contributing, you agree that your contributions may be distributed under the MIT License.
